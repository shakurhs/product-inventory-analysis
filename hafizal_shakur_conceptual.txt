Jawaban

1. NoSQL merupakan kependekan dari "Not only SQL", yaitu sebuah database non tabular dengan kemampuan penyimpanan data
   secara independen berbeda dengan relational database (tabular), yang biasa digunakan untuk menyimpan data berupa
   key-value, documents, graph, dll.

2. Penggunaan NoSQL dibutuhkan ketika data yang dimiliki bersifat non tabular atau semi terstruktur, data dengan skala 
   horizontal yang tinggi, data yang strukturnya cenderung berubah, dan data yang real-time atau membutuhkan waktu yang 
   cepat untuk processing. Sedangkan RDBMS digunakan ketika data berberntuk tabular atau terstruktur, memiliki skala
   kecil sampai medium, dan memiliki kompleksitas yang tinggi untuk melakukan query data.

3. Beberapa tools NoSQL lainnya adalah MongoDB dan Cassandra. MongoDB memiliki kelebihan seperti memiliki query language yang variatif,
   meyimpan data dalam bentuk JSON sehingga mudah untuk menghandle semi dan non struktural data. Di lain hal, Cassandra lebih baik
   dalam menghandle data dengan skala horizontal yang lebih besar lagi dan lebih baik pula pada skenario analisis real-time.

4. Apache Airflow adalah sebuah open-source platform yang digunakan untuk memonitor, men-develop, dan menjadwalkan proyek
   yang pengerjaannya dalam bentuk batch dengan konsep Directed Acyclic Graph (DAG). Pada dasarnya AIrflow digunakan untuk melakukan
   automasi terhadap pengerjaan sebuah proyek dalam urutan pengerjaan dan waktu yang tepat.

5. Great Expectations merupakan sebuah tools yang biasa digunakan dalam Data Engineering untuk proses Data Validation dengan
   melakukan beberapa validasi mengenai karakteristik dari sebuah dataset dan memastikan data tersebut dalam kriteria baik.

6. Batch Processing adalah sebuah metode untuk menjalankan beberapa pekerjaan dengan dibagi ke dalam grup atau batch tanpa melibatkan
   interaksi user dala prosesnya. Biasanya batch processing digunakan untuk otomatisasi dari kegiatan yang sifatnya repetisi. Tools yang
   digunakan meliputi Apache Spark, Apache Hadoop,  AWS Batch dan lainnya. Batch Processing seringnya diaplikasikan pada monthly payroll,
   report, mem-backup data dan pekerjaan-pekerjaan repetitif lain.
